# Договоры

**Дата:** 13.09.2026  
**Экран:** `/contracts` (только десктоп)  
**Данные:** таблица `contracts`, та же база, что у рабочего приложения

**13.09.2026:** поиск убран из шапки сайта. Поле стоит справа, сразу над фильтрами.

Справочник договоров компании. Каждый договор привязан к объекту и контрагенту.

## Что умеет

- Список слева — таблица: номер, объект, контрагент (тип — маленький бейдж под именем), период, сумма, статус. Справа: поиск, фильтры по типу и статусу, кнопка добавления, сводка
- Поиск справа над фильтрами. Ищет по номеру, контрагенту и объекту. Крестик в поле очищает запрос. В шапке сайта поиска нет
- Клик по строке открывает большое окно. Закрывается только крестиком или кнопкой «Закрыть», клик снаружи окно не закрывает
- В окне закладки на всю ширину: **Общие данные**, **Сметы**, ДС, Акты, Документы, Финансы.
- Вкладка **Финансы** по договору: счета взаиморасчётов этого договора, показатели «к оплате / оплачено / долг», таблица счетов и кнопка «Новый счёт». Клик по строке открывает счёт — там оплаты, документы и PDF. Новый счёт из этой вкладки сразу привязан к договору (объект и контрагент подставляются)
- Вкладка **Сметы** по договору:
  - Выбор сметы из выпадающего списка (с отображением сумм) или просмотр всех позиций всех смет договора разом
  - Сводные показатели: общая сумма смет и общее количество позиций
  - Полноценная таблица позиций с поддержкой настройки колонок, колонок выполнения, фильтрации превышений и всплывающего окна деталей (сводка, выполнение, история правок)
  - Экспорт позиций договора в Excel (.xlsx)
  - Загрузка новых смет из Excel (.xlsx) через модальное окно: предпросмотр структуры, валидация колонок, подсчет строк и суммы, скачивание шаблона сметы, пакетный импорт
  - Безопасное удаление выбранной сметы с подтверждением в диалоговом окне
- Создание, изменение, удаление — из окна карточки
- НДС считается сам по ставке и переключателю «включён в стоимость», как в приложении

Изменения сразу пишутся в рабочую базу.

## Правила

- Видны только договоры активной компании
- Номер, дата заключения, контрагент, объект и сумма обязательны
- Дата окончания не может быть раньше даты заключения
- Тип: заказчик, подряд, поставка. Если в базе тип неизвестен — заказчик
- Статус: в работе, приостановлен, завершён. Если в базе статус неизвестен — в работе
- Сводка считает все договоры компании, даже если список отфильтрован
- Если к договору уже привязаны сметы или другие данные, удаление может не пройти — так устроено в базе
- Права на экране пока временные: полный доступ. В базе дополнительно стоят RLS-политики по компании и `check_permission`

## Типы

| Тип в базе | На экране | Цвет |
| --- | --- | --- |
| `customer` | Заказчик | тёмный |
| `subcontract` | Подряд | зелёный |
| `supply` | Поставка | жёлтый |

## Статусы

| Статус в базе | На экране | Цвет |
| --- | --- | --- |
| `active` | В работе | зелёный |
| `suspended` | Приостановлен | жёлтый |
| `completed` | Завершён | серый |

Не путать со статусами объектов: там приостановка — `paused`.

## НДС

Формула как в приложении (`computeVatAmount`):

- ставка 0 или сумма 0 → НДС 0
- включён в стоимость: `сумма × ставка / (100 + ставка)`
- сверху: `сумма × ставка / 100`
- результат округляется до копеек

В форме сумма НДС только для просмотра. Удержания и генподрядные вводятся руками, при сохранении не пересчитываются.

## База

Таблица `contracts`. RLS включён: свои компании (`get_my_company_ids`) и права модуля `contracts` (`read` / `create` / `update` / `delete`).

Индексы: первичный ключ по `id`, `contractor_id`, `object_id`. Триггера на таблице нет: при изменении веб сам пишет `updated_at`.

В карточке и форме не показываются служебные поля `created_at` и `updated_at`.

Связанные таблицы: `contractors` (имя), `objects` (название).

## Пока нет

Это есть в приложении, в вебе пока нет:

- сметы внутри карточки
- дополнительные соглашения
- акты КС-2
- файлы договора
- финансы и выработка

Серверные функции экспорта (`export-contract-estimate-addenda`, `export-contract-estimate-execution` и другие) веб не вызывает.
