# Документация веб-приложения

Папка `react_app` — отдельный сайт. Flutter-приложение от неё не зависит.

## Меню

Слева те же разделы, что в приложении. Группа **Справочники** раскрывается.

Сверху — название раздела. На компьютере справа аватар: профиль и выход. Если вышла новая сборка — колокольчик с точкой, по нажатию можно обновить приложение. **В шапке сайта поля поиска нет.**

Поиск живёт в самом разделе: у списков справочников — справа над фильтрами (сотрудники, договоры, контрагенты, объекты, пользователи, заявки); у смет, журнала работ и табеля — в панели фильтров над таблицей.

Внизу меню — переключатель тем: светлая, тёмная, фирменная. Под ним — «Помощь» (подсказки по сменам). Подробности: [theme.md](./theme.md).

Открываются Главная, [ГТ Диск](./gt-disk.md), [ГТ Чат](./gt-chat.md), [Объекты](./objects.md), [Контрагенты](./contractors.md), [Договоры](./contracts.md), [Сметы](./estimates.md), [Сотрудники](./employees.md), [Работы](./works.md), [Журнал работ](./work-journal.md), [Табель](./timesheet.md), [ФОТ](./payroll.md), [Заявки](./purchase-requests.md), [Взаиморасчёты](./settlements.md), [Профиль](./profile.md), [Пользователи](./users.md), [Роли](./roles.md) и [Компания](./company.md). Пункты без права «просмотр» скрыты. На компьютере неперенесённые разделы с правом остаются в списке бледнее; по нажатию — сообщение, что раздел пока в приложении.

**Телефон (ширина меньше 768px):** в меню и по адресу доступны [Главная](./home.md), [ГТ Диск](./gt-disk.md), [ГТ Чат](./gt-chat.md), [Сотрудники](./employees.md), [Работы](./works.md), [Заявки](./purchase-requests.md), [Взаиморасчёты](./settlements.md), [Компания](./company.md) и [Профиль](./profile.md). Остальные адреса сразу переводят на работы (если есть право просмотра смен) или в профиль. После входа открывается главная; у нового пользователя сначала завершение профиля и выбор организации ([auth.md](./auth.md)). Шапка у каждого мобильного раздела своя — меню и название, без аватара; общая шапка сайта на телефоне скрыта и не дублируется. Внизу бокового меню — «Помощь» (подсказки по сменам), имя и переход в профиль (без кнопки выхода). Сайт в браузере не открывается: нужна установка как PWA (иконка на экране «Домой»). На компьютере сайт работает в обычном окне браузера. На телефоне экран нельзя увеличить пальцами (щипок и двойное касание): масштаб зафиксирован, прокрутка обычная.

## Доступ и данные

- Вход по телефону и SMS-коду. Новый пользователь сначала заполняет ФИО и создаёт организацию или вступает по коду приглашения: [auth.md](./auth.md).
- Данные изолированы по компании: пользователь видит только данные организаций, в которых состоит. Правило действует во всех разделах (миграция `20260919170000_fix_multi_tenant_leaks.sql`).

## Запуск

```bash
cd react_app
npm install
npm run dev
```

Адрес: http://localhost:3000

Код сайта на GitHub — отдельный репозиторий [dimnok/projectgt_react](https://github.com/dimnok/projectgt_react). Из корня большого проекта: `./scripts/push_react_app.sh`. Flutter-репозиторий при этом не обновляется.

Ключи подключения: файл `.env.local` по образцу `env.example`.

Телефоны везде пишутся как `+7 900 000 00 00`.
