# Документация веб-приложения

Папка `react_app` — отдельный сайт. Flutter-приложение от неё не зависит.

## Меню

Слева те же разделы, что в приложении. Группа **Справочники** раскрывается.

Сверху — название раздела. На компьютере справа аватар: профиль и выход. Поиск: на широком экране в шапке, на узком — под сводкой. Enter с другого экрана открывает Объекты.

Внизу меню — переключатель тем: светлая, тёмная, фирменная. Подробности: [theme.md](./theme.md).

Открываются Главная, [Объекты](./objects.md), [Контрагенты](./contractors.md), [Договоры](./contracts.md), [Сметы](./estimates.md), [Сотрудники](./employees.md), [Работы](./works.md), [Журнал работ](./work-journal.md), [Табель](./timesheet.md), [Профиль](./profile.md), [Пользователи](./users.md) и [Роли](./roles.md). Пункты без права «просмотр» скрыты. На компьютере неперенесённые разделы с правом остаются в списке бледнее; по нажатию — сообщение, что раздел пока в приложении.

**Телефон (ширина меньше 768px):** в меню и по адресу доступны [Работы](./works.md) и [Профиль](./profile.md). Остальные разделы скрыты и сразу переводят на смены. Шапка смен и профиля — одна и та же мобильная: меню и название, без аватара. Внизу бокового меню — имя и переход в профиль (без кнопки выхода). Сайт в браузере не открывается: нужна установка как PWA (иконка на экране «Домой»). На компьютере сайт работает в обычном окне браузера.

## Запуск

```bash
cd react_app
npm install
npm run dev
```

Адрес: http://localhost:3000

Ключи подключения: файл `.env.local` по образцу `env.example`.

Телефоны везде пишутся как `+7 900 000 00 00`.
