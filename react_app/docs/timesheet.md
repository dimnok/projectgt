# Табель рабочего времени

**Дата:** 12.09.2026  
**Экран:** `/timesheet` — `TimesheetDesktop`. Только компьютер. На телефоне раздел в меню не показывается; адрес переводит на работы или в профиль.  
**Данные:** `work_hours` (закрытые смены), `employee_attendance` (ручная посещаемость), `employees`, `objects`, `works` (открытые смены сегодня).  
**Режим:** календарная сетка учёта часов за месяц. Приложение (Flutter) этим экраном не меняется.

**12.09.2026 (обновление 2):** внедрена строгая изоляция объектов и сотрудников. Пользователи без глобальных прав (`objects.read` / `employees.read` / `isOwner`) видят в фильтре «Объекты» и в расчётах табеля исключительно объекты, закреплённые за их профилем (`profile.objectIds`). При отсутствии назначенных объектов табель возвращает пустой список. При переходе в карточку сотрудника из табеля блоки ставок, суточных и вкладка «Финансы» надёжно скрыты для пользователей без прав `payroll.read` / `employees.update` / `isOwner`.

**12.09.2026 (обновление 1):** оптимизирован веб-модуль. Устранён избыточный сетевой запрос к ставкам сотрудников (`employee_rates`), запросы выполняются параллельно. Таблица переведена на независимую мемоизацию строк для плавной работы без лагов. Колонки зафиксированы с непрозрачным фоном и правильным z-index, таблица занимает всю высоту экрана (`data-fill-viewport`) с ровными отступами. Ячейки дней сделаны строго квадратными (40×40 px), убран лишний визуальный шум выходных полос в теле таблицы.

## Макет

Одна карточка на весь экран: сверху панель месяца и фильтров, ниже таблица с закреплённой шапкой, колонками сотрудника и строки итогов.

```
┌────────────────────────────────────────────────────────────────────────┐
│ [<] Сентябрь 2026 [>]  [Поиск ФИО]  [Объекты ▾] [Должности ▾] [Состав ▾]  [Excel] │
├────────────────────────────────────────────────────────────────────────┤
│ ☐ │ Сотрудник            │ 1 │ 2 │ 3 │ … │ 31 │ Итого                 │
│   │                      │ пн│ вт│ ср│ … │ чт │                       │
├────────────────────────────────────────────────────────────────────────┤
│ ☐ │ Иванов Иван          │ 8 │ 8 │   │ … │ 8  │ 168                   │
│   │ Монтажник            │   │   │   │   │    │                       │
├────────────────────────────────────────────────────────────────────────┤
│ Итого                    │ 8 │ 8 │   │ … │ 8  │ 328                   │
└────────────────────────────────────────────────────────────────────────┘
```

- В шапке сайта поиска нет. Поиск по ФИО — только в панели фильтров над таблицей.
- Выпадающие списки «Объекты», «Должности», «Состав» оформлены как фильтры журнала работ: кнопка, бейдж выбранного, пункты с галочками.
- Углы таблицы обрезаются по скруглению карточки (`clip-path`), чтобы закреплённые ячейки не выходили за рамку.
- ФИО в таблице — тот же шрифт, что в списке сотрудников: обычный размер, полужирный. Должность мельче и серее. Высота строки чуть плотнее за счёт отступов, не за счёт шрифта.

## Что умеет

### Месяц и поиск

- Кнопки предыдущего и следующего месяца. Название месяца и год на русском.
- Следующий месяц недоступен, если уже открыт текущий.
- Поиск по фамилии, имени и отчеству. Крестик в поле очищает запрос.

### Фильтры

- **Объекты** и **Должности** — множественный выбор. На кнопке число выбранных.
- **Состав:**
  - часы за период: все / с часами / без часов;
  - смена сегодня (если в открытом месяце есть сегодняшний день): все / в открытой смене сегодня / не в смене сегодня.

### Таблица

- Слева закреплены чекбокс и колонка «Сотрудник» (320 px, ФИО полностью помещаются). Справа закреплено «Итого».
- Закреплённые колонки имеют повышенный приоритет слоёв (z-index) и 100% непрозрачный фон, поэтому данные при горизонтальном и вертикальном скролле не наслаиваются и уходят под шапку.
- Таблица занимает всю высоту экрана (`data-fill-viewport`) и доходит до нижнего края окна с аккуратным одинаковым отступом.
- Выходные выделены в шапке (красный цвет чисел и названий дней). Ячейки тела таблицы имеют чистый монохромный фон без вертикальных полос.
- Сегодняшний день в шапке отмечен акцентным кружком.
- Часы в ячейках квадратные (40×40 px) без цветной заливки по объекту. Ручная отметка (не из смены) выделена квадратным бейджем.
- Подсказка при наведении контрастная и легко читаемая (название объекта и текст заметки). Появляется, если есть примечание или открытая смена.
- Клик по ФИО открывает карточку сотрудника. Иконка календаря в строке сотрудника открывает окно посещаемости.
- Внизу строка итогов по дням и общая сумма за месяц по текущим фильтрам.

### Окно посещаемости

- В списке объектов показывается **название**, не код. Назначенные сотруднику объекты отмечены «(назначен)».
- Календарь месяца: одна сетка Пн–Вс. Выходные красные. Сегодняшнее число — кружок.
- Часы из закрытой смены нельзя править: замок и подпись «смена».
- Ручные часы вводятся прямо в ячейку. Пустая ячейка без нуля. Можно вводить дробные значения (8.5 или 8,5).
- «Будни по 8ч» заполняет рабочие дни без смены. «Очистить» снимает только ручные часы.
- Сводка: ручные часы, часы смен, всего.
- Сохранение пакетом через RPC `upsert_employee_attendance_batch`. Таблица на экране обновляется сразу.

### Excel

- Файл собирается в браузере (`ExcelJS`), без отдельной серверной функции.
- В файле: шапка, числа и дни недели, подсветка выходных, **цвета объектов в ячейках часов**, итоги, легенда объектов внизу.
- Можно выгрузить всех видимых или только отмеченных чекбоксами. На кнопке тогда число выбранных.

## Права

Раздел в меню, если есть право `timesheet.view` (`timesheet.read`). Проставление часов — `timesheet.create` / `timesheet.update`.

**Разграничение по объектам:**
- Пользователи с глобальным доступом (владельцы компании, права `objects.read` или `employees.read`) видят в табеле и в фильтре все объекты компании.
- Линейные пользователи без прав на просмотр сотрудников/объектов видят в фильтре «Объекты» и в сетке табеля исключительно те объекты, которые привязаны к их профилю (`profiles.object_ids`). Чужие объекты не отображаются в фильтре, а часы и открытые смены по ним изолированы.

**Защита финансовых данных при переходе в карточку:**
- При клике на ФИО сотрудника из табеля открывается карточка сотрудника.
- Блок ставок и выплат («СТАВКИ И ВЫПЛАТЫ» на вкладке «Обзор») и вкладка «Финансы» автоматически скрыты для пользователей без прав `isOwner`, `payroll.read` или `employees.update`. Линейный персонал видит только общие кадровые данные (стаж, привязки к объектам, контакты, спецодежду, реквизиты).

---

## Данные

Часы смен — `work_hours`. Ручные часы — `employee_attendance`. Список людей — сотрудники с признаком учёта в табеле. Открытые смены сегодня — таблица `works`.

Цвета объектов (`timesheet-palette.ts`) используются при выгрузке в Excel. На экране таблица монохромная.
