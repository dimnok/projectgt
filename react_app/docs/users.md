# Пользователи

**Дата:** 13.09.2026  
**Экран:** `/users` (только компьютер; на телефоне адрес переводит на работы или в профиль)  
**Данные:** `company_members`, `profiles`, `employees`, `roles`

**13.09.2026:** поиск убран из шапки сайта. Поле стоит справа, сразу над фильтрами. Переключатель «Новая версия» переводит человека на сайт `app.progt.ru`: в старом приложении сразу появляется экран перехода.

Список людей активной компании. Список виден при праве `users.read`.

## Что умеет

- Список слева: имя, роль, статус, карточка сотрудника, объекты. Справа: поиск, фильтр, сводка
- Фильтр: все / с карточкой / без карточки
- Поиск справа над фильтрами. Ищет по ФИО, почте, роли, телефону, имени сотрудника и названиям объектов. Крестик в поле очищает запрос. В шапке сайта поиска нет
- Назначение, смена и снятие привязки к сотруднику — право `users.update` (владелец, «Супер-админ», роль с этим правом)
- Назначение объектов компании — то же право `users.update`. Объекты других компаний на профиле не затираются. База не даёт обычному пользователю сменить свои объекты.
- Назначение роли — только владелец компании (так устроено в базе)
- Перевод на новую версию (сайт) — право `users.update`. В сводке есть счётчик «На сайте»

## Правила

- Видны пользователи активной компании
- Телефон на экране: `+7 900 000 00 00`

## Пока нет

Это есть в приложении, в вебе пока нет:

- смена статуса пользователя
- приглашение нового пользователя
