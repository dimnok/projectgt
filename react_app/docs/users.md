Список людей активной компании. Список виден при праве `users.read`.

## Что умеет

- Список: имя, роль, статус, карточка сотрудника, объекты. Сверху: поиск, фильтр, счётчик
- Фильтр: все / с карточкой / без карточки
- Сортировка — клик по заголовку колонки: сначала прямое направление, второй клик — обратное, третий возвращает исходный порядок. Сортировать можно по имени, роли, статусу, карточке, числу объектов и новой версии. Равные значения идут по алфавиту
- Поиск над списком. Ищет по ФИО, почте, роли, телефону, имени сотрудника и названиям объектов. Крестик в поле очищает запрос. В шапке сайта поиска нет
- Назначение, смена и снятие привязки к сотруднику — право `users.update` (владелец, «Супер-админ», роль с этим правом). Делается нажатием на значок в колонке «Карточка»
- Назначение объектов компании — то же право `users.update`. Объекты других компаний на профиле не затираются. База не даёт обычному пользователю сменить свои объекты.
- Назначение роли — только владелец компании (так устроено в базе)
- Смена статуса («Отключить доступ» / «Вернуть доступ») — только владелец компании, из меню «…», с подтверждением. Отключённый при входе попадает на экран «Доступ отключён»; данные и роль сохраняются. Свою строку владелец отключить не может — пункт скрыт
- Перевод на новую версию (сайт) — право `users.update`. В списке есть переключатель «Новая версия»

## Правила

- Видны пользователи активной компании
- Статус — это `company_members.is_active`: доступ человека к компании. Менять его в базе разрешено только владельцу (`get_owned_company_ids`)
- Телефон на экране: `+7 900 000 00 00`
