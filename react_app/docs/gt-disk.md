# ГТ Диск

**Дата:** 13.09.2026  
**Экран:** `/gt-disk` — `GtDiskPage`: ширина **&lt; 768px** → `GtDiskMobile`, иначе `GtDiskDesktop`.  
**Телефон:** раздел доступен в меню и по адресу (вместе с главной, сотрудниками, работами и профилем). Шапка сайта скрыта, своя мобильная шапка.

Это **макет только в веб-приложении**. В мобильном/десктопном приложении Flutter раздела нет.

**Компьютер:** окно в духе Finder. Слева избранное и объекты. В центре крупные папки. Один щелчок выделяет, двойной — открывает. Сверху кнопки назад/вперёд и поиск, снизу путь.

**Телефон:** список папок. По нажатию снизу открывается содержимое.

## Разделы объекта

Чертежи (актуальные и старые), договоры, сметы, акты, фото, прочее.

Нажатие на пример файла только сообщает, что это макет.
