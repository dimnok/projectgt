# Сметы

**Дата:** 03.09.2026  
**Экран:** `/estimates` (только десктоп)  
**Данные:** та же база, что у рабочего приложения. Только чтение.

Список смет компании и позиции выбранной сметы. В вебе нельзя создать, изменить или удалить смету.

## Что умеет

- Над таблицей современный блок KPI: сумма сметы/договора/объекта, количество позиций, процент выполнения и общий бюджет по договору с круговым индикатором выполнения
- По умолчанию фильтры не выбраны: сверху отображается сводка по всем сметам компании
- При выборе «Объекта» и «Договора» (когда в поле «Смета» выбрано «Все сметы») таблица выводит все позиции всех смет выбранного договора
- При выборе конкретной сметы таблица фильтрует позиции только выбранной сметы, а блок KPI отображает метрики этой сметы
- Поиск размещён прямо в панели фильтров (не в шапке сайта). Выполняет мгновенную фильтрацию строк таблицы по наименованию и артикулу с кнопкой быстрой очистки
- В таблице позиций: система, подсистема, номер, наименование, артикул, производитель, единица, количество, цена, сумма (строки упорядочены по Системе, Подсистеме и Номеру)
- Всплывающее окно исполнения и деталей позиции с переключателем «Выполнение / Сводка / Правки»: появляется при наведении курсора на количество (в колонке «Количество» по смете, а также в колонке «Выполнено»), а при нажатии фиксируется (не исчезает при уводе мыши). Числа отображаются в чистом виде без лишних значков. Окно можно свободно растягивать как за правый, так и за левый нижний угол. В шапке окна выводятся система, подсистема, цена и сумма позиции. В окне предусмотрены три режима:
  - **Выполнение**: подробный список смен по датам (Дата, Участок, Этаж, Количество, Кто внёс).
  - **Сводка**: структурированная группировка по участкам и этажам (для каждого участка отображается общий объем, а внутри — список этажей с выполненным объемом).
  - **Правки**: хронология создания и всех ручных изменений полей позиции сметы (дата и время, автор правки, конкретные изменённые поля с отображением значений `было → стало`).
  Внизу окна выводятся общее выполнение по позиции и остаток/превышение сметы (либо параметры сметы).
- Колонки автоматически подстраиваются под ширину данных, а всё оставшееся пространство отдаётся колонке «Наименование» с многострочным переносом текста
- Шапка таблицы закреплена при прокрутке. Лишние колонки скрываются кнопкой настройки колонок (шестерёнка в строке фильтров). Наименование скрыть нельзя. Список скрытых колонок запоминается в браузере
- Панель быстрых действий над таблицей:
  - Кнопка **«Выполнение»**: по нажатию справа появляются 4 колонки (количество и сумма выполненного, количество и сумма остатка). Суммы считаются как цена сметы × количество. Данные подгружаются только после нажатия. В строке «Итого» считаются сумма сметы, сумма выполненного и остаток по сумме.
  - Кнопка **«Превышения»**: компактная кнопка с иконкой предупреждения и бейджем количества превышений. Отображается только тогда, когда в выбранной смете (или договоре) есть позиции с превышением выполнения над сметой (`overrunCount > 0`). По нажатию фильтрует строки, показывая только такие позиции, и открывает блок колонок выполнения. Повторное нажатие возвращает полный список.
  - Компактная зеленая кнопка **«Excel»**: выгружает текущую выборку позиций в полноценный файл `.xlsx` прямо в браузере (через `exceljs`), не нагружая сервер.
- В сгенерированном Excel-файле:
  - Закрепленная двухуровневая шапка с цветовым разделением блоков («Позиция сметы», «По смете / договору», «Выполнение», «Остаток»)
  - Включенный автофильтр Excel по второй строке заголовков для удобной сортировки и фильтрации
  - Автоматический подбор ширины колонок по фактическому содержимому ячеек без нежелательного переноса строк в наименованиях
  - Живые формулы Excel: расчет сумм позиций (`Кол-во × Цена`), сумм выполнения (`Кол-во вып. × Цена`), остатка количества (`План − Вып.`) и остатка суммы (`Ост. кол-во × Цена`)
  - Формулы `SUM(...)` в строке «Итого» для денежных сумм (итоги по количеству не суммируются)
  - Подсветка отрицательного остатка красным шрифтом и денежный формат чисел `#,##0.00 ₽`

## Правила

- Видны только сметы активной компании и только строки с `visible_in_estimates_module = true` — как в приложении
- Список групп берётся той же серверной функцией `get_estimate_groups`, что и в приложении
- Позиции читаются из представления `estimates_with_contracts`
- Факт по строкам берётся той же серверной функцией `get_estimate_completion_by_ids`, что и в приложении
- Процент выполнения считает сервер по объёму: факт из работ / план сметы
- Права на экране пока временные: только просмотр. В базе дополнительно стоят RLS-политики по компании и `check_permission`

- Добавление новой позиции сметы через диалоговое окно с автоматическим подсчетом суммы (количество × цена).
- Редактирование любых полей позиции (система, подсистема, номер, наименование, артикул, производитель, ед. изм., количество, цена) с автоматической фиксацией дельты изменений в `estimate_item_history`.
- Удаление отдельных позиций сметы с диалоговым окном подтверждения.
- Импорт смет из файлов Excel (.xlsx) и удаление сметных файлов из договора.

Таблицы модуля: `estimates` и связанные. Веб их не меняет.
