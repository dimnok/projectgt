# Журнал работ

**Дата:** 13.09.2026  
**Экран:** `/work-journal` — `WorkJournalDesktop`. Только компьютер. На телефоне раздел в меню не показывается; адрес переводит на работы или в профиль.  
**Данные:** те же смены и позиции, что в приложении. Новые таблицы не создаются.  
**Режим:** таблица выполненных работ по объекту. Приложение (Flutter) этим экраном не меняется.

В приложении этот раздел называется «Выгрузка». В вебе он открывается как **«Журнал работ»**.

**13.09.2026:** Shift + клик по наименованию подставляет его в поиск и запускает фильтрацию. Обычный клик по названию ничего не делает. Клик по дате по-прежнему открывает смену.

**06.09.2026:** переход в смену из журнала — клик по дате открывает окно только со списком работ этой смены; строка, с которой пришли, подсвечена. Excel — три листа (Журнал работ, ПТО, Общий), файл собирается в браузере.

---

## Макет

Как у смет: одна карточка на весь экран. Сверху фильтры, ниже таблица с закреплённой шапкой и строкой итогов. Список карточек, как у контрагентов, не используется.

```
┌─────────────────────────────────────────────────────────────────┐
│  Объект  Поиск  Система  Участок  Этаж     [Excel] [даты] [⚙] │
├─────────────────────────────────────────────────────────────────┤
│  Таблица (шапка закреплена)                                     │
│  …                                                              │
│  Итого по всей выборке                                          │
├─────────────────────────────────────────────────────────────────┤
│  Страницы (если больше 250 строк)                               │
└─────────────────────────────────────────────────────────────────┘
```

- Корневой контейнер: `data-fill-viewport` — экран занимает высоту окна.
- В шапке сайта поиска нет. Поиск по наименованию — только в строке фильтров над таблицей.
- Объект обязателен. Без него таблица не загружается.
- Период дат необязателен (иконка календаря справа). Если задан, действует и на таблицу, и на списки фильтров.
- Поиск по наименованию — с паузой 0,5 секунды. Очистка крестиком в поле, отдельной кнопки «Сбросить» нет. **Shift + клик** по названию в таблице вставляет это наименование в поле поиска.
- Система, участок и этаж — множественный выбор. Список значений приходит с сервера и сужается каскадом.
- На странице до 250 строк. Итоги по количеству и сумме считаются по **всей** выборке, не только по текущей странице.

## Что умеет

### Таблица

Колонки на экране: дата, система, подсистема, участок, этаж, наименование, единица, количество, цена, сумма.

**Shift + клик** по наименованию вставляет полный текст в поиск. Обычный клик по названию ничего не открывает.

Объект выбирается в фильтре. Колонок «Объект» и «М-15» на экране нет. Номер позиции на экране не показывается (он есть в Excel).

Ширина колонок считается по содержимому текущей страницы и по заголовку. Всё свободное место отдаётся «Наименованию». Лишние колонки скрываются шестерёнкой. **«Дата» и «Наименование» скрыть нельзя.** Выбор запоминается в браузере (`react-work-journal-table-layout`).

### Окно смены

Клик по **дате** открывает окно поверх журнала. Фильтры и страница журнала не сбрасываются.

В окне:

- шапка: дата смены, статус, объект;
- сразу список **работ этой смены** (тот же список, что вкладка «Работы» в разделе Работы);
- строка, с которой открыли журнал, **подсвечена** и прокручивается в видимую область;
- вкладок «Обзор» и «Сотрудники» нет.

Если у строки нет идентификатора смены — окно не открывается, показывается сообщение.

Права в окне — как в разделе **Работы**: журнал сам только для просмотра. Если смену можно править, в окне доступны количество, изменение и удаление позиции. После сохранения список журнала обновляется.

Смена читается по идентификатору из таблицы `works` (`getWork`). Список позиций — тот же, что у карточки смены.

### Excel

Зелёная кнопка справа. Файл собирается в браузере (ExcelJS), как в сметах. Серверная функция `export-work-search-pto` **не вызывается**.

В файл попадают все строки текущих фильтров, не только открытая страница (порциями по 1000, не больше 100 000 строк). Нужен выбранный объект и хотя бы одна строка.

В файле три листа. Оформление как у смет: двухуровневая шапка, цвета групп, автофильтр, строка «Итого».

| Лист | Что внутри | Как схлопывается |
| --- | --- | --- |
| **Журнал работ** | По сменам, как на экране, плюс колонка **№** | Без схлопывания. Дата, система, подсистема, участок, этаж, №, наименование, ед., кол-во, цена, сумма. Сумма — формула `Кол-во × Цена` |
| **ПТО** | Сводка для ПТО | Система + подсистема + участок + этаж + № + наименование + М-15 + единица. Количества складываются. Колонки: система, подсистема, участок, этаж, №, наименование, М-15, ед., кол-во |
| **Общий** | Сводка по договорам | Объект + договор + система + подсистема + № + наименование + М-15. Количества и суммы складываются. Колонки: объект, договор, система, подсистема, №, наименование, М-15, ед., кол-во, цена, сумма |

Группировка и сортировка листов ПТО и Общий совпадают с приложением.

Имя файла: `Журнал_работ`, при необходимости объект и период дат.

## Правила

- Видны объекты активной компании, по которым уже есть смены.
- Права экрана пока временные: модуль `workJournal` — только просмотр. Создание, правка и удаление в журнале выключены.
- Правка позиций в окне смены идёт через права модуля `works` (кто открыл смену / супер-админ / статус смены) — как на экране Работы.
- Excel не меняет базу, только читает уже выбранные строки.

## Пока нет

Это есть в приложении, в вебе пока нет:

- ВОР Excel и PDF
- правка и удаление строки прямо в таблице журнала (правка — только в окне смены)
- переход на полный экран смены (обзор, фото, люди)
- правый клик «Перейти к смене», как в приложении (в вебе — клик по дате)

## База

Чтение через те же серверные функции, что в приложении:

- `get_distinct_work_object_ids` — объекты, по которым есть смены
- `get_work_items_available_filters` — доступные система / участок / этаж
- `search_work_items_with_aggregates` — страница таблицы и итоги

Окно смены: таблица `works` (одна смена по id) и `work_items` той смены. RLS как у раздела Работы.

Связанные данные в строке поиска: объект, договор, позиция сметы, М-15 — приходят в ответе поиска, на экране журнала не все показываются.
