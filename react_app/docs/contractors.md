# Контрагенты

**Дата:** 02.09.2026  
**Экран:** `/contractors` (только десктоп)  
**Данные:** таблица `contractors`, та же база, что у рабочего приложения

Справочник заказчиков, подрядчиков и поставщиков компании.

## Что умеет

- Список слева. Справа: фильтр по типу, кнопка добавления, сводка по всем карточкам компании
- Поиск сверху: имя, ИНН, директор, телефон, email, код и название ОКВЭД
- Карточка по клику: полное имя, сфера деятельности (название и код ОКВЭД), коды, адреса, люди, контакты. Краткое имя в шапке не дублируется. Пустые поля скрыты. Телефон, почта и сайт — ссылки. Телефон: `+7 900 000 00 00`
- Создание, изменение, удаление

Изменения сразу пишутся в рабочую базу.

Пустое поле в форме сохраняется в базу как `null`, не как пустая строка. Во Flutter с 02.09.2026 такой `null` читается как пустой текст, иначе падал весь список контрагентов.

## Правила

- Видны только контрагенты активной компании
- Система налогообложения выбирается из списка, не вводится руками: ОСНО, УСН «Доходы», УСН «Доходы минус расходы», АУСН (оба варианта), ЕСХН, ПСН, НПД или «Не указана». НДС — отдельный переключатель и ставка
- Сфера деятельности: в форме вводится только код ОКВЭД. Название подставляется из справочника, руками его писать не нужно. В базу пишется код (`43.29`). На карточке: `название (код)`. Если код неизвестен — показывается сам код. Старые записи вида `[код] название` или `название (код)` читаются
- Тип по умолчанию — заказчик. Если в базе тип пустой или неизвестный — тоже заказчик
- Сводка считает все карточки компании, даже если список отфильтрован
- Если у контрагента есть договоры, удаление может не пройти — так устроено в базе

## ОКВЭД

Справочник: ОКВЭД 2 (ОК 029-2014), изменение №89 от 01.08.2026. Файл: `src/lib/okved/okved2.json` (выгрузка classifikators.ru от 10.08.2026).

Когда появится поиск по ИНН (DaData), код можно будет подставлять оттуда. Название по-прежнему будет браться из этого справочника.

В мобильном приложении справочника пока нет: там видно сырое значение из базы.

## Типы

| Тип в базе | На экране | Цвет |
| --- | --- | --- |
| `customer` | Заказчик | тёмный |
| `contractor` | Подрядчик | зелёный |
| `supplier` | Поставщик | жёлтый |

Тип виден на карточке. У открытой карточки рамка и подкрашенный заголовок того же цвета.

## Пока нет

Это есть в приложении, в вебе пока нет:

- поиск по ИНН (DaData)
- логотип
- банковские счета
- мобильный экран
