# Вход и онбординг

**Дата:** 19.09.2026  
**Экраны:** `/login`, `/complete-profile`, `/onboarding`, `/access-disabled`
**Данные:** Supabase Auth (SMS OTP), `profiles`, `companies`, `company_members`, `company_invitations`

Единая точка входа сайта. После проверки сессии и профиля сайт сам показывает нужный экран — тот же порядок, что в приложении.

## Порядок проверок

1. Нет сессии — экран входа.
2. Профиль не загрузился — сообщение об ошибке, «Повторить», «Выйти».
3. `profiles.status = false` — «Доступ временно отключён».
4. Нет ФИО — «Завершение регистрации».
5. Нет активной компании (`profiles.last_company_id`) — онбординг.
6. Роль ещё не назначена — открыт только профиль с подсказкой.
7. Иначе — главная.

## Что умеет

### Вход (`/login`)
- Ввод телефона с маской `+7 900 000 00 00`.
- Код из SMS: шесть ячеек, автоподстановка из сообщения, автопроверка при вводе шестой цифры.
- Повторная отправка кода через 30 секунд.
- Понятные сообщения: неверный код, просроченный код, лимит попыток, сеть.

### Завершение регистрации (`/complete-profile`)
- Обязательный ввод ФИО (минимум фамилия и имя).
- Сохраняется в `profiles.full_name` и `profiles.short_name`.

### Онбординг (`/onboarding`)
- «Создать организацию» — полная форма реквизитов: поиск по ИНН (DaData), наименования, ИНН, КПП, ОГРН, ОКПО, налогообложение и НДС, контакты, адреса, руководство, бухгалтерия. Создатель становится владельцем.
- «Вступить по коду» — код приглашения из 8 символов.

### Доступ отключён (`/access-disabled`)
- Кнопка «Проверить доступ» и выход.

## Сервер

- `create_company_for_user(p_data jsonb)` — SECURITY DEFINER, создаёт организацию, назначает создателя владельцем и ставит её активной. Миграция `20260919160000_create_company_for_user.sql`.
- `redeem_company_invitation(p_code)` — вступление по коду (существующая функция).
- Создание компании раньше шло прямыми вставками из клиента; в вебе — только через функцию.

## Правила

- Телефон на экране: `+7 900 000 00 00`, в Auth уходит E.164 `+7XXXXXXXXXX`.
- Роль берётся из `company_members` активной компании.
- Экраны входа и онбординга показываются вне основной оболочки приложения и доступны на телефоне.
- Данные изолированы по компании: после входа пользователь видит только данные организаций, в которых состоит (миграция `20260919170000_fix_multi_tenant_leaks.sql`).
