# Темы оформления

**Дата:** 20.09.2026  
**Где:** веб-приложение `react_app`. Flutter-приложение этими темами не управляется.

Тем семь. Светлые: **Светлая**, **Фирменная**, **Песочная**, **Пастельная**. Тёмные: **Тёмная**, **Северная**, **Графит**.

Переключатель — в профиле, раздел «Система» (и на компьютере, и на телефоне): плитки с образцом цвета, названием и пояснением. На компьютере есть и быстрый доступ — внизу левого меню кнопка «Тема: …» со списком.

Выбор запоминается в браузере (на устройстве), в аккаунт не пишется: на другом устройстве будет своя тема. По умолчанию — тема системы (светлая или тёмная).

Светлая, тёмная и фирменная — как раньше, их вид не менялся.

Северная собрана по мотивам популярной палитры Nord, Графит — нейтральная серая тёмная тема. Цвета статусов (зелёный, жёлтый, красный) к темам не относятся: в светлых темах они как в светлой, в тёмных — как в тёмной.

Контраст текста проверен по WCAG: основной текст на фоне и на карточках — от 10:1, второстепенный — не ниже 4.8:1, подписи на кнопках — не ниже 5:1.

## Как это устроено

- **Список тем** — `src/config/themes.ts`: код, название, пояснение, образец цветов и цвет строки браузера. Единственное место, где перечислены темы.
- **Цвета тем** — `src/styles/globals.css`: блоки `:root` (светлая), `.dark` (тёмная), `.brand` (фирменная), `.sand`, `.pastel`, `.nord`, `.graphite`.
- **Переключение** — `next-themes` в `src/app/providers.tsx`: список тем берётся из `themeIds`. На страницу вешается класс темы (`light`, `dark`, `brand`, `sand`, `pastel`, `nord`, `graphite`).
- **Тёмные детали.** Правило `dark:` в стилях применяется к `.dark`, `.nord` и `.graphite` (строка `@custom-variant dark` в `globals.css`). Если добавить новую тёмную тему, её класс нужно вписать туда же — иначе часть элементов останется светлой.
- **Переключатели:** профиль — `src/features/profile/ui/profile-appearance.tsx`; левое меню — `ThemeToggle` в `src/layouts/desktop/sidebar.tsx`.
- **Строка браузера на телефоне** — фон темы из справочника (`ThemeColorSync` в `src/app/providers.tsx`). Для тёмных тем цвет тёмный.
- На установленном приложении iPhone верх прозрачный (`black-translucent`). Пока открыто окно снизу, цвет строки (`theme-color`) становится тёмным — иначе iOS рисует светлую полоску с часами поверх затемнения. После смены настроек верха приложение лучше закрыть и открыть с иконки.

## Как добавить тему

1. Добавить блок с переменными в `globals.css` (35 значений; удобно скопировать соседнюю тему и заменить цвета; для тёмной указать `color-scheme: dark`).
2. Добавить тему в `themeOptions` в `src/config/themes.ts` (код, название, пояснение, образец, цвет строки браузера).
3. Для тёмной темы — вписать её класс в `@custom-variant dark` в `globals.css`.
4. Проверить контраст текста и посмотреть разделы с таблицами, формами и окнами.

Больше нигде темы перечислять не нужно: переключатели и цвет строки браузера берут список из справочника.
