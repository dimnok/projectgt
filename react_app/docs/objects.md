# Модуль «Объекты»

**Дата:** 13.09.2026  

Строительные объекты компании. Данные те же, что в рабочем приложении.

**13.09.2026:** поиск убран из шапки сайта. Поле стоит справа, сразу над фильтрами.

## Что умеет

- Список объектов слева. Справа сверху: поиск, фильтры и кнопка «добавить». Справа ниже: сводка — всего и разбивка по статусам (по всем объектам, даже если список отфильтрован)
- Поиск справа над фильтрами. Ищет по названию, адресу и описанию. Крестик в поле очищает запрос. В шапке сайта поиска нет
- Просмотр деталей по клику на карточку. Если колонка узкая, название, адрес и описание идут столбиком, а у кнопок «Изменить» и «Удалить» остаются только значки
- Создание, изменение, удаление

Изменения сразу сохраняются в рабочую базу.

## Статусы

| Статус | Цвет |
| --- | --- |
| Активный | зелёный |
| Приостановлен | красный |
| Завершён | жёлтый |

Статус виден на карточке. У открытой карточки рамка и слегка подкрашенный заголовок того же цвета. В деталях статус не дублируется — его меняют через «Изменить».

Новые и уже существующие объекты без статуса считаются активными.

## Данные

Таблица `objects`: название, адрес, описание, статус, компания.

Список берётся по активной компании пользователя.

В Flutter статус пока не показывается и не затирается.
