# Веб-приложение (react_app)

Отдельная веб-версия ProjectGT. Flutter от этой папки не зависит.

Документация модулей: [docs/](./docs/README.md)

## Запуск

```bash
cd react_app
npm install
npm run dev
```

Откройте http://localhost:3000

## Сейчас есть

- Вход по телефону и SMS-коду (тот же аккаунт, что в текущем приложении)
- Меню слева и верхняя панель. Работают Главная, [Объекты](./docs/objects.md) и [Контрагенты](./docs/contractors.md)
- Три темы: светлая, тёмная и фирменная. [theme.md](./docs/theme.md)

## Пока нет

- Остальные модули: пункты в меню есть, экранов ещё нет
- В контрагентах пока нет поиска по ИНН, логотипа и банковских счетов. Код ОКВЭД вводится вручную, название подставляется само ([подробнее](./docs/contractors.md))

## Важно

- Команды `npm` только внутри `react_app`
- Корневой Flutter-проект не менять
- Изменения объектов и контрагентов в вебе сразу пишутся в рабочую базу

Переменные: скопируйте `env.example` в `.env.local`.
