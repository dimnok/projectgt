# Путь пользователя (мини-промпт)

**Дата:** 30 августа 2026  
**Источник:** `SplashController`, `AuthGate`, `app_router.dart`, `app_drawer.dart`, `main.dart`

Используй этот файл как краткий контекст: кто куда попадает после установки и входа. Не выдумывать экраны вне этого списка.

---

## Старт

1. Запуск → `/` Splash (логотип, статус загрузки).
2. Параллельно: если версия приложения ниже минимальной → `/force-update` (выход только обновлением). Источник: `watchAppVersionProvider` в `main.dart`.
3. Splash проверяет сессию:
   - нет сессии → `/login`
   - есть сессия → грузит профиль → `/home`

`/login` и `/home` оба рисует **AuthGate** — он выбирает экран по статусу.

---

## Вход

Телефон → OTP (Telegram или SMS). Регистрации отдельной нет.

---

## AuthGate (после входа, строго по порядку)

| Условие | Экран |
|---|---|
| Загрузка сессии | Спиннер |
| `profiles.status = false` | Доступ отключён |
| Нет сессии / ошибка входа | Вход (телефон + OTP) |
| Профиль не загрузился | Ошибка + «Повторить» / «Выйти» |
| Нет ФИО | Завершение регистрации (фамилия и имя) |
| Нет компании (`last_company_id`) | Онбординг |
| `profiles.prefer_web_app = true` | Экран «Новая версия» (ссылка на app.progt.ru) |
| Есть компания, нет роли, и не owner | Ожидание роли |
| Всё ок | Главная |

Owner роль не ждёт. Без роли (`roleId` пустой) — только экран ожидания, без рабочих данных.

---

## Онбординг

Два пути:

- **Создать компанию** → пользователь становится owner → Главная.
- **Вступить по коду** → компания назначена → если админ ещё не выдал роль → Ожидание роли.

---

## Главная (`/home`)

Дашборд: KPI, открытая смена, календарь смен, прогресс договора, план работ, заявления.  
Блок «Нужно согласовать» — только если пользователь согласующий заявок.

Ширина ≥ 1100 — десктопный дашборд. Уже — вертикальный список.

Быстрые кнопки (если есть право `read`): Договоры, Сметы, Планы, Табель, Команда, Финансы, Подрядчики. «Финансы» на телефоне скрыты.

---

## Меню (боковая панель)

Пункт виден только при праве `read` на модуль. Нет права — пункта нет. Зашли без права — «Доступ запрещён».

**Всегда:** Главная, аватар → Профиль, выход.

**По правам:**

- CASH FLOW
- Взаиморасчёты
- Заявки
- Работы
- Материал
- ТМЦ
- Табель
- Сотрудники
- Подрядчики
- Справочники → Объекты / Контрагенты / Договоры
- Сметы
- ФОТ
- Выгрузка
- Пользователи
- Управление версиями
- Управление ролями

Компанию можно переключить в шапке меню. Добавить компанию — снова онбординг (без выхода).

---

## Только десктоп / широкий экран

На iOS/Android и на web уже 900 px **нет в меню и нельзя открыть:**

- Материал
- CASH FLOW
- Выгрузка
- ТМЦ

Заглушка: «модуль недоступен на этом устройстве».

---

## Профиль

`/profile` — свой профиль.  
Дальше: уведомления, настройки, финансы, имущество.  
Админ: `/users`, чужой профиль `/profile/:userId`.  
Сотрудник без права на список всё равно видит **свою** карточку `/employees/:id`.

## Повторный запуск

Сессия жива → Splash → `/home` → сразу нужный экран AuthGate (без повторного OTP).  
Сессии нет → Вход.

## Чего нет

- Отдельной регистрации.
- Telegram-модерации как экрана входа.
- Экрана «заявка на доступ» — вместо него «Ожидание роли».
